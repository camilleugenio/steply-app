# Steply

Steply is a mobile app that helps users stay on top of their daily physical 
activity. It tracks steps in real time, logs workouts like walking, running, 
and cycling, and keeps users motivated through streak tracking and customizable 
daily goals. The app also provides weekly and historical activity views, along 
with contextual information such as weather and current location.

## Features

- Real-time step tracking
- Workout logging (walking, running, cycling)
- Customizable daily goals with progress indicators
- Streak tracking to encourage consistency
- Weekly and historical activity views
- Contextual weather and location info
